# Yukakad Docs

Dokumen ini berisi ringkasan dan panduan project rebuild Yukakad.

## Daftar dokumen
- [PROJECT_PLAN.md](PROJECT_PLAN.md) — roadmap lengkap dan arah produk
- [PHASES.md](PHASES.md) — detail fase per tahap pengembangan

## Quick start
1. baca [PROJECT_PLAN.md](PROJECT_PLAN.md)
2. ikuti urutan fase di [PHASES.md](PHASES.md)
3. mulai dari Phase 0 sampai Phase 4 untuk fondasi yang stabil

## Stack utama
- Frontend: Next.js + TypeScript + Tailwind
- Backend: Go + REST API
- Database: PostgreSQL
- Cache: Redis
- Storage: S3-compatible object storage

## Catatan penting
Legacy repository hanya dipakai sebagai reference behavior, bukan source yang langsung ditransfer.
